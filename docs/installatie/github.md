## GitHub account aanmaken

⚠️ **Belangrijk:** zorg ervoor dat je een GitHub account hebt dat gekoppeld is aan je **HOGENT-e-mailadres**.

!!! note "Stappenplan"
    1. Open een webbrowser.
    1. Surf naar [GitHub](https://github.com).
    1. Klik rechtsboven op de pagina op de knop ++'Sign up'++
    1. Vul je HOGENT-e-mailadres in bij **Email** en kies een unieke gebruikersnaam en een wachtwoord.
    1. Voltooi de registratieprocedure.
        - Kies voor het **Free plan**.
        - Controleer je e-mail en klik op de link in de **bevestigingsmail.**
        - Stel eventueel je **profiel** verder in.
