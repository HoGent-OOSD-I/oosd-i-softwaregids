## Installatie van Visual Paradigm

⚠️ **Belangrijk:** Tijdens de analyse en ontwerp fase van software ontwikkeling wordt gebruik gemaakt van verschillende **UML diagrammen**. Visual Paradigm is software om, onder andere, UML diagrammen te tekenen. Visual Paradigm is commerciële software maar via HOGENT krijg je een **activatie code** die toelaat dat je de standaard versie van Visual Paradigm gratis kan gebruiken.

### Visual Paradigm downloaden en installeren
!!! note "Stappenplan"
    1. Open een webbrowser.
    1. Surf naar [Visual Paradigm downloads](https://www.visual-paradigm.com/download/).
    1. Download **Visual Paradigm FREE Trial**.
    1. Voer het gedownloade installatiebestand uit.
        - Accepteer de gebruikersovereenkomst
        - Je kunt de standaardinstellingen aanvaarden en telkens op ++'next'++ klikken

### Visual Paradigm Standard activeren    
!!! note "Stappenplan"
    1. Start een eerste keer Visual Paradigm.
    1. Klik ++'Skip'++ bij het "Default Client Configuration" scherm
    1. Selectie van het licentietype
        - Klik ++'Activate'++ bij **Academic Licence**
    1. Gebruik volgende gegevens voor de licentie:
        - Activation Code: deze vind je bij de rubriek **Extra Leermaterialen en Software** in de **[studiewijzer van de Orion-cursus](https://orion.hogent.be/d2l/common/dialogs/quickLink/quickLink.d2l?ou=23143&type=lti&rcode=2EB887A3-877F-4602-A59F-C00F7C31C5E9-585&srcou=6606&launchFramed=1&framedName=Studiewijzer)**
        - Name: **[jouw naam]**
        - Email: **[jouw HOGENT-e-mailadres]**
    1. Klik ++'Activate'++
    1. Bekijk je mail en kopieer en plak de verificatiecode die je van Visual Paradigm kreeg in het verificatie venster.
