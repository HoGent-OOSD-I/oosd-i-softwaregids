## Installatie van Git

⚠️ **Belangrijk:** Git is een essentieel hulpmiddel binnen de opleiding. Het wordt gebruikt om broncode te beheren en samen te werken aan softwareprojecten. Zorg ervoor dat Git correct geïnstalleerd is voordat je verdergaat.

!!! note "Stappenplan"
    1. Open een webbrowser.
    1. Surf naar [Git](https://git-scm.com/).
    1. Klik op ++'Downloads'++.
    1. Kies de versie die overeenkomt met jouw besturingssysteem/processor.
    1. Voer het gedownloade installatiebestand uit.
    1. Doorloop de installatiewizard.
        - Behoud de standaardinstellingen.
        - Klik telkens op ++'Next'++.
    1. Klik op ++'Install'++.
    1. Wacht tot de installatie voltooid is.
    1. Klik op ++'Finish'++.

### Controleren van de installatie

1. Open een terminal:
    - Druk op ++'win'++ (dit is de Windows-toets)
    - Typ **cmd**.
    - Druk op ++'enter'++.
 
2. Voer het volgende commando uit:

    ```bash
    git --version
    ```

3. Controleer of een versienummer wordt weergegeven, bijvoorbeeld:

    ```text
    git version 2.xx.x
    ```

1. Verschijnt een versienummer, dan is Git correct geïnstalleerd.
