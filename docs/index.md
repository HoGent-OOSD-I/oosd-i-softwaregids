# OOSD I - Softwaregids

Welkom bij de softwaregids voor OOSD I (Object-Oriented Software Development I). Op deze pagina vind je instructies om alle tools die je dit academiejaar 2026-2027 nodig hebt op een correcte manier te installeren en in te stellen op je laptop. Voorzie ongeveer 1,5 uur om alle software te installeren en te configureren.

## Installatie
### 📌 Belangrijke richtlijnen
- **Respecteer de volgorde:** Installeer alle software strikt in de volgorde van het navigatiemenu. Het overslaan van stappen kan later voor fouten zorgen.
- **Configuratie:** Vergeet na de installatie niet de configuratiestappen te doorlopen. Let goed op: sommige stappen zijn **verplicht** om je examen correct te kunnen afleggen. Dit staat duidelijk aangegeven bij de desbetreffende stappen. 
- **Besturingssysteem:** Kies in elk geval steeds de software die past bij jouw besturingssysteem.

### 💻 Jouw besturingssysteem
Voor je met de installatie begint, controleer je best welk besturingssysteem en welk type processor je laptop gebruikt.

#### Windows
1. Open het **Start-menu** en ga naar **Instellingen**
2. Ga in het menu naar **Systeem**
3. Kies **Info**
    - Noteer je Windows-versie 
    - Noteer het type systeem
        - **x64-processor**, kies bij software-downloads steeds voor **x64** (of x86_64)
        - **ARM-processor**, kies bij software-downloads steeds voor **ARM64**

#### macOS
1. Klik linksboven in je scherm op het **Apple-logo**
2. Kies **Over deze Mac**
3. Noteer je **macOS-versie**
4. Noteer het type **processor**
    - **Intel**, kies bij software-downloads steeds voor **Intel** of **x64** 
    - **Apple M1, M2, M3, M4** (of hoger): kies bij software-downloads steeds voor **Apple Silicon** of **ARM64**

## Configuratie

### 📌 Belangrijke richtlijnen
- **IntelliJ IDEA** is de ontwikkelomgeving die je tijdens je opleiding heel intensief zult gebruiken. Een correcte configuratie zorgt voor een comfortabele werkomgeving. Sommige configuratiestappen zijn **verplicht**. Aan het begin van het examen moet je aantonen dat jouw IDE conform deze verplichte richtlijnen is ingesteld.
- Configureer ook **Visual Paradigm** volgens deze gids.Dit vereenvoudigt het volgen van de lessen omdat je configuratie dan gelijk loopt met die van je lector.
