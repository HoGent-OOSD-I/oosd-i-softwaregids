Installatie van de JDK: Java Development Kit

⚠️ Belangrijk: De programmeertaal Java staat centraal in de OLOD's OOSD I & OOSD II. Het is cruciaal om de juiste versie van de JDK (Java Development Kit) te installeren. Voor het academiejaar 26-27 werk je met de Oracle JDK 25. Zorg dat je deze installeert voordat je verdergaat.

Stappenplan

  1. Open een webbrowser.
  2. Surf naar Oracle Java Downloads.
  3. Download de versie die overeenkomt met jouw besturingssysteem/processor.
  4. Voer het gedownloade installatiebestand uit.
  5. Klik op 'Next'.
  6. Behoud de standaardinstellingen.
  7. Klik op 'Next'.
  8. Klik op 'Install'.
  9. Wacht tot de installatie voltooid is.
  10. Klik op 'Finish'.

Controleren van de installatie

  1. Open een terminal.
    • Druk op win.
    • Typ cmd.
    • Druk op enter.

  2. Voer het volgende commando uit:

    java --version

  3. Controleer of een versienummer wordt weergegeven dat begint met 25.

    Bijvoorbeeld:

    java 25

  4. Voer vervolgens het volgende commando uit:

    javac --version

  5. Controleer of opnieuw een versienummer wordt weergegeven dat begint met 25.

  6. Verschijnt in beide gevallen een versienummer, dan is de installatie correct uitgevoerd.
